# data_subject_request
Automated DSR portal for Personal Data Protection Act in Sri Lanka

## Introduction
This is a REST API developed using Springboot framework along with Java programming language as a backend service which connects into a postgreSQL database with regards to data insertion, deletion, modification and retrieval. This REST API will be containing the major operations that are designated to be operated via this approach. 

## Technology Stack

> Java

> Springboot

> PostgreSQL

> GitHub (Version controlling)

> JWT (For authentication & authorization purposes)

> Postman API
